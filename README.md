# ☕ Grão & Código

Site institucional de uma cafeteria fictícia que combina café, tecnologia e coworking.

## 📌 Sobre o projeto

O Grão & Código foi desenvolvido como projeto acadêmico de Desenvolvimento Web, com o objetivo de praticar a criação de páginas utilizando HTML e CSS.

## ✨ Páginas disponíveis

- **Início:** apresentação da cafeteria.
- **Cardápio:** bebidas e acompanhamentos.
- **Sobre nós:** história e valores da marca fictícia.
- **Coworking:** apresentação do espaço de trabalho.
- **Contato:** informações e formulário demonstrativo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Layout responsivo
- JavaScript básico incorporado ao formulário de contato

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Utilize o menu superior para navegar entre as páginas.

## 📷 Recursos

As imagens são carregadas do Unsplash e precisam de conexão com a internet.

## ⚠️ Observações

O formulário de contato é demonstrativo e não envia mensagens para um servidor.
